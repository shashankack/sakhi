# UX design

## Principles

- Supportive peer tone, not clinic form
- Reflect user’s words back
- Themes = education associations, not diagnoses
- Show uncertainty and overlap conditions
- Red flags get a calm but distinct urgent panel

## Pages

| Route | Purpose |
|-------|---------|
| `/` | Brand, one-liner, disclaimer, CTA → chat |
| `/chat` | Main product |
| `/learn` | Static PCOS education |
| `/about` | Full disclaimer, privacy, emergency |

## Chat message types

1. User bubble  
2. Assistant reflective text  
3. Theme cards (1–3)  
4. Care card (urgency + questions)  
5. Source chips  
6. Red-flag block (when applicable)  
7. Persistent disclaimer / safety banner  

## Empty state

Demo buttons: Hinglish cluster, urgent red flag, English acne/mood, optional Devanagari.

## Visual direction (for UI)

Avoid generic purple-AI look. Prefer calm sage/stone health atmosphere; expressive display font; mobile-first.
Detailed component ownership: `docs/ui/PAGE_MAP.md`.
