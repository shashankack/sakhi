# Corpus writing guide

## File naming

Use kebab-case: `cycles-irregular.md`, `hirsutism-acne.md`, `red-flags-when-urgent.md`.

## Required sections per topic file

1. **Title**
2. **theme_ids** (from `docs/contracts/THEME_IDS.md`)
3. **Plain-language explanation**
4. **PCOS education context** (association, not diagnosis)
5. **Other possible causes / overlaps**
6. **Self-care notes** (non-prescriptive)
7. **Care pathway** (who to see, how soon)
8. **Questions for a clinician**
9. **Lay aliases** (English + Hinglish/Hindi phrases people actually say)

## Example header

```markdown
---
theme_ids: [cycle_irregularity]
urgency_default: soon
---

# Menstrual cycle changes
```

## Tone

Supportive, clear, grade 8–10 reading level. Explicit uncertainty. Never “you have PCOS.”
