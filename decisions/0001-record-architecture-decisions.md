# ADR 0001 — Record architecture decisions

## Status

Accepted

## Context

Hackathon moves fast; four agents may contradict each other without a decision log.

## Decision

Record significant choices as ADRs under `decisions/`. Integration owns this folder. See ADRs 001–004 for current product decisions.

## Consequences

- Shared rationale for “why no cloud LLM” and ownership rules
- New decisions get a numbered ADR instead of chat-only agreement
